# PortfolioCoreDay
💻 Kullandığım Teknolojiler ve Yöntemler:
• ASP.NET Core 8.0
• Entity Framework Core (Code First + Migration)
• SQL Server
• Razor View & ViewComponent
• HTML, CSS, Bootstrap 5
• SweetAlert2
• İlişkili Tablo Yapısı
• SOLID Prensipleri
________________________________________
⚙️ Admin Paneli Özellikleri:
• Modern ve dinamik bir kullanıcı arayüzü geliştirerek sade, akıcı ve yönetilebilir bir panel oluşturdum.
• Kart yapısı sayesinde projeler görsel olarak daha etkileyici biçimde listelendi.
• Yönetim paneline entegre ettiğim 10 farklı istatistik alanıyla veriye dayalı karar süreçleri desteklendi.
• Kullanıcı yönlendirmelerini iyileştirmek adına özel bir 404 hata sayfası tasarlandı.
________________________________________
👨‍💻 Kullanıcı Paneli Özellikleri:
• “Hakkımda” bölümü veritabanı ile entegre edilerek içerikler dinamik hale getirildi.
• “Hizmetlerim” alanında, son 6 hizmet otomatik ve dinamik biçimde listelendi.
• “İletişim” formu veritabanı bağlantılı olacak şekilde yapılandırılarak mesajlar kayıt altına alındı.
• Kullanıcı deneyimini artırmak için SweetAlert2 ile etkileşimli bildirimler entegre edildi.
